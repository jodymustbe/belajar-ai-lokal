## Hari ke-3: Pemahaman Neural Network Training, Inference, dan Base Model

**Target:** Memahami konsep cara belajar LLM

### Ringkasan Konsep
* **Neural Network Training** Terdapat dua hal:
  1. Input = Sequence of Tokens
  2. Output = Prediction what comes next, updating the sequence
* **Neural Network Internals:** Input sequence tokens + Parameters --> Giant Mathematical Expression
* **Inference:** Tujuan dari Inference :
  1. Bikin data baru dari model
  2. Melihat pola yang telah diinternalisasi pada parameter
* **Alur Inference:**
  1. Token;
  2. Neural Network;
  3. Probabilities;
  4. Sample; and
  5. Token Predict.
* **Base Model:** Terdapat dua hal jika ingin membuat base model:
  1. Memiliki python code yang berisi sequence work
  2. Parameters

### Hasil Pengujian Inference (`qwen3.5:2b-q4_K_M`)
* **Simulasi Sampler (`NumPy`):**
  * Pada `temperature=0.2`, probabilitas token teratas (`' normal'`) terkonsentrasi hingga **98,0%** (hampir deterministik).
  * Pada `temperature=1.0` dan `1.2`, distribusi probabilitas melebar sehingga token kandidat ke-2 (`' kering'`, **27,3%**) dan ke-3 (`' basah'`, **15,9%**) berpeluang terpilih saat *sampling*, sementara `top_k=3` memangkas token berisiko (`' error'`) menjadi **0,0%**.
* **Prefill vs Decode (`qwen3.5:2b-q4_K_M`):**
  * **Prefill:** 57 token diproses dalam **0,246 s** (**231,8 tok/s**) secara paralel.
  * **Decode:** 60 token ditulis dalam **0,682 s** (**87,9 tok/s**) secara sekuensial (*autoregressive*) — **2,64x lebih lambat** dari *prefill*.
* **Konsistensi vs Variasi (`3x Run`):**
  * `temperature=0, seed=42` menghasilkan output **100% identik** di setiap percobaan.
  * `temperature=1.2, top_k=40, top_p=0.9` menghasilkan 3 kalimat berbeda dan memunculkan halusinasi istilah (*"Kontrol Awan, Penuaan Tanah"*), membuktikan efek pelebaran distribusi probabilitas pada tahap *sampling*.
