## Hari ke-9: Manajemen Memori Percakapan Stateless & Protokol Dual-API Lokal (`chat_cli.py`)

**Target:** Memahami sifat *stateless* server LLM lokal, membandingkan dialek protokol native Ollama (`/api/chat`) dengan standar OpenAI-compatible (`/v1/chat/completions`), serta membangun antarmuka CLI interaktif (`chat_cli.py`) berbasis *standard library* Python yang portabel.

### Konsep Dasar & Manajemen State Percakapan
- **Sifat Stateless Server Inferensi:** Server LLM tidak menyimpan riwayat percakapan antar-request. Klien wajib mengirimkan ulang seluruh array `messages` pada setiap giliran percakapan agar konteks tetap terjaga.
- **Penguncian System Prompt:** Elemen `{"role": "system", ...}` selalu dikunci pada indeks ke-0 array `messages` agar instruksi perilaku model tidak tergeser sepanjang sesi.
- **Eksekusi Dual-API 100% Lokal:** Mengubah mode endpoint ke `/v1/chat/completions` tetap berjalan sepenuhnya secara lokal pada `localhost:11434` tanpa memanggil layanan cloud OpenAI; perbedaan hanya terletak pada dialek protokol agar arsitektur `jharness` bersifat portabel.

### Perbandingan Protokol `/api/chat` vs `/v1/chat/completions`

| Aspek Protokol | Native Ollama (`/api/chat`) | OpenAI-Compatible (`/v1/chat/completions`) |
| :--- | :--- | :--- |
| **Format Stream** | NDJSON (JSON murni per baris) | SSE (baris berawalan `data: `) |
| **Lokasi Token Konten** | `chunk["message"]["content"]` | `chunk["choices"][0]["delta"]["content"]` |
| **Penanda Akhir Stream** | `"done": true` | Baris literal `data: [DONE]` |
| **Telemetri & Reasoning** | Menyertakan metrik GPU (`eval_count`, `eval_duration`, `load_duration`) dan field `message.thinking` | Disembunyikan secara default |

### Implementasi Artefak Kode (`chat_cli.py`)
- **Tanpa Dependensi Eksternal:** Dibangun menggunakan *standard library* Python (`urllib.request` dan `json`) untuk menangani koneksi HTTP dan parsing stream secara ringan.
- **Streaming & Penyimpanan Konteks:** Mendukung tampilan output token secara *real-time* sekaligus mengelola penyimpanan riwayat percakapan di dalam array `messages`.
- **Perintah Interaktif CLI:** Dilengkapi perintah `/switch` untuk berpindah endpoint API (`/api/chat` <-> `/v1/chat/completions`) di tengah sesi, `/history` untuk memeriksa isi array memori percakapan, serta `/exit` untuk mengakhiri sesi.

### Kesimpulan Arsitektur Dual-API
> Pengelolaan array `messages` di sisi klien yang dipadukan dengan parser dual-API memungkinkan `jharness` berjalan 100% lokal dengan visibilitas penuh terhadap telemetri GPU Ollama (`/api/chat`), sekaligus menjaga portabilitas kode terhadap standar ekosistem OpenAI (`/v1/chat/completions`).
