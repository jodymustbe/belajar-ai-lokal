### Hasil Siklus Hidup `keep_alive` (`qwen3.5:2b-q4_K_M`, `num_ctx=2048`)
* **`keep_alive = "0"`:** Model langsung dilepas (`Loaded: False`) segera setelah respons selesai dan RAM sistem langsung kembali ke baseline awal (`~3.450 MiB`).
* **`keep_alive = "5m"`:** Model dipertahankan aktif di memori (`Loaded: True`). Selama termuat, runtime mengalokasikan ~900 MiB *host/CUDA staging buffer* di RAM sistem, dan kembali pulih sepenuhnya setelah di-*unload* manual (`3.294,1` $\rightarrow$ `3.277,1 MiB`).
* **Catatan API `keep_alive = -1`:** Pada REST API Ollama, nilai `-1` harus dikirim sebagai tipe data **integer JSON (`-1`)**, bukan string (`"-1"`), agar tidak memicu `400 Bad Request` dari parser durasi Go.

### Kesimpulan Arsitektur Memori
> Pada sistem 4 GB VRAM dan 8 GB RAM, **`qwen3.5:2b-q4_K_M` adalah satu-satunya model yang aman dijalankan secara bebas hingga konteks `8192` token** dengan performa stabil di atas `81 tok/s`. Model kelas 4B (`qwen3:4b` atau `phi4-mini:latest`) hanya layak dipanggil secara on-demand dengan konteks terbatas (`num_ctx=2048`), penguncian layer GPU manual, dan `keep_alive=0` setelah selesai agar RAM sistem tidak terbebani.
